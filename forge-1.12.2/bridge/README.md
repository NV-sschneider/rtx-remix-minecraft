# Shared RTX Remix bridge and Java 8 interop

Fabric and Forge compile the same Minecraft-independent Java facade, C API
header, and JNI implementation from repository-root `rtxremix-java/`. This
directory contains only the Forge OpenGL adapter, its native build entry point,
and Java 8/native contract tests. The shared sources target Remix C API
**0.16.0** and require the runtime pinned by `packman/remix-sdk.packman.xml`.

The shared Java facade has no external dependencies and compiles with Java 8.
`Transform.fromTRS` accepts quaternion components `(x, y, z, w)` so clients can
use their own math library without adding a facade dependency. Fabric still
uses Java 21 for its mod and native build; the Forge adapter is compiled with
the Java 8 JDK's JNI declarations.

The Forge native build defines `REMIX_PIN_RUNTIME_DLL` to keep a successfully
initialized runtime DLL resident until process exit. The client still releases
its owned resources and calls `Shutdown`; the runtime's device-accounting warning
at process exit remains unresolved and also occurs in the Fabric regression.
Keeping the DLL loaded avoids the pinned
runtime's loader-lock teardown deadlock in the legacy client. The standard Fabric
native build does not define this option, so its module-loading behavior is unchanged.

## Build and verification

From the repository root:

```powershell
.\forge-1.12.2\scripts\build-bridge.ps1
.\forge-1.12.2\scripts\build-bridge.ps1 -RuntimeDirectory .\remix-runtime\win64
.\forge-1.12.2\scripts\build-bridge.ps1 -RuntimeDirectory .\remix-runtime\win64 -GpuSmoke
```

The script uses the Java 8 JDK under the repository's `.tools/jdk8/` directory
and Visual Studio x64 C++ tools. Outputs are
`forge-1.12.2/bridge/build/libs/rtxremix-java8-0.16.0.jar` and
`forge-1.12.2/bridge/build/native/win64/remixbridge.dll`. `-SkipNative` builds and
tests only the Java side. `-JdkPath` selects another Java 8 JDK.

Checks cover the shared-source boundary, command-line redaction, packed vertex and transform buffers,
all structure identifiers against the pinned C header, Java/native version
agreement, and native extension allocation/free under `-Xcheck:jni`.
The C++ build includes the declarations generated by `javac -h` so incompatible
JNI signatures fail compilation. Static assertions verify C-side buffer layout.
Supplying `-RuntimeDirectory` additionally verifies native runtime loading and
API negotiation in a separate Java process. `-GpuSmoke` creates an offscreen,
nonactivating Windows OpenGL window and path traces a textured emissive triangle
for 30 frames. It then patches the retained sRGB texture from red to green and
renders 30 more frames without replacing its material, mesh, or instance. It
checks the same interior pixels changed color, framebuffer copies, preserved GL
state, and native shutdown. The before/after images are saved as
`forge-1.12.2/bridge/build/gpu-smoke/gpu-smoke.png` and
`forge-1.12.2/bridge/build/gpu-smoke/gpu-smoke-texture-patched.png`.
The normal-map stage compares two identically lit surfaces, first with matching
runtime-converted normals and then with one pre-encoded `NORMAL_OTH` texture.
It patches that retained texture and checks the lighting changes relative to the
untouched reference. Its three images use the `gpu-smoke-normal-` prefix.
The window is shown offscreen because the runtime skips rendering invisible
windows. The test does not launch Minecraft or prove in-game rendering.

Before the repository layout migration, the GPU test passed with Java 8,
an RTX 5090, driver 621.1.0 and the pinned runtime
`remix-main+71a581da`. Runtime shutdown completed and the JVM exited successfully.
The runtime still reported its own device-object accounting message at exit.

## Consumer contract

Compile repository-root `rtxremix-java/src` together with this module's
`src/main/java`, or package the resulting JAR's classes. Do not copy the facade
or C header into this directory. Stage `remixbridge.dll` beside the pinned runtime's `d3d9.dll`,
or put the bridge on `java.library.path`. Keep original runtime package/cache
directories read-only; build outputs belong in a separate staging directory.

All GPU scene operations belong to the render thread. JNI buffers must be
direct, little-endian, large enough for their declared counts, and start at
offset zero (use a direct slice for a nonzero source offset). Vertices use a
64-byte stride; unsigned 32-bit indices use a 4-byte stride; transforms hold
12 row-major floats in 48 bytes. The native functions read the direct buffer
address, not its Java position.

Before loading the runtime in a launcher-started process, call
`RemixAPI.redactCommandLineOptions` with Minecraft's `--username`, `--accessToken`,
`--uuid`, `--xuid`, and `--clientId` option names. Native crash reports include
the process command line. This preserves upstream's protection of those copies.

## OpenGL interoperability for LWJGL 2

`com.nvidia.rtxremix.forge.interop.LegacyGlInterop` supplies a separate, game-independent
native adapter for OpenGL external memory and timeline semaphores missing from
LWJGL 2's Java bindings. It obtains entry points with `wglGetProcAddress`; the
original `com.nvidia.rtxremix` JNI ABI remains unchanged.

Start Remix with `interopImage=true` and its Vulkan swapchain enabled, then create
`LegacyGlInterop` from `dxvkGetInteropInfo()`. After each world `submit`, call
`acquireToFramebuffer` with the latest interop information and Minecraft's FBO.
It waits and copies native color while retaining shared-image ownership. After
Minecraft draws its HUD and screens, `finishFromFramebuffer` copies their final
color back and signals the client-completion timeline. Call `present` with that
value, the current nonzero `hwndOverride`, and `skipVulkanSwapchain=0`. With both
copies using `flipY=true`, leave `interopFlipY=0`. Remix then composites its menu.
The presentation hook replaces OpenGL's swap while preserving LWJGL's resize
bookkeeping and input polling. It remains active during worldless and disabled
frames after initialization: submit and use `acquire` without a native-to-GL copy
to preserve the vanilla framebuffer before finishing and presenting it.

`releaseAcquired` releases an aborted frame without copying and is idempotent.
`copyToFramebuffer` retains the earlier immediate-release path for offscreen
tests that use `forceNoVkSwapchain=true` and `skipVulkanSwapchain=1`. It cannot
include the native menu, which is composited after the interop read during
presentation. The GPU test covers both transfer directions and ownership guards;
native menu pixels must be verified from the actual game window.

The adapter imports resized images automatically, synchronizes before replacing
them, and restores framebuffer bindings, texture binding, scissor and sRGB state.
It currently copies color only; depth requires separate implementation and validation.
The Forge smoke fixture verified camera and
color alignment for its small terrain scene. Keep the API and adapter alive
across rendering toggles: recreating only the adapter would reset its timeline
counter against the same runtime semaphore. Close the adapter while its original
GL context is current, then destroy the game window, then shut down the runtime.
